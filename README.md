# 材料集：坚果云材料看板界面预览

仅用于确认界面和交互。学校、文件路径和收集状态全部为示例；三类初始材料条目按用户提供的清单顺序整理：申报机构37项、申报项目41项、机构变更28项。

## 已包含

- 总览：六类根文件夹卡片、递归文件数量、原有层级浏览、文件名及路径搜索。
- 申报材料进度：按学校和具体事项建立清单，选择三类模板，查看已收集、部分收集、待确认、未收集和不适用状态。
- 本校清单可修改名称、别名、排列位置、适用性、所需文件份数及对应示例文件，支持新增材料和独立人工审核。
- 预览修改仅保存在当前浏览器 localStorage，可恢复示例。

## 部署范围

这是无构建步骤的静态 GitHub Pages 预览。相对路径资源支持项目子目录部署，未使用外部字体、追踪脚本或第三方托管组件。

没有邮箱登录后台、共享数据库、坚果云网络请求或任何文件上传、下载、预览、改名、删除接口。不要将坚果云应用密码、真实目录、文件内容或团队账号写入此公开仓库。正式版的邮箱认证、共享状态及只读目录连接需要独立后台，尚未部署。

## 本地查看

使用任意静态文件服务器打开本目录的 index.html。界面预览不需要账户或密码。
